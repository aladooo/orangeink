# 自检器规则手册（docs/self-check.md）

点工具栏「自检」，橙墨会对**预览区渲染结果**跑一遍规则检查——不是查 Markdown 源码，而是查最终复制进公众号的那份 HTML。这样查到的问题就是公众号线上真正会拦/会误判的问题。

面板分两档：

- **违规（error）**：会被公众号线上检测拦截或误判「结构异常」的问题，发布前必须修；
- **提示（warn）**：可读性 / 观感类问题，公众号线上不查，但建议处理。

检出项可以点击定位到预览区对应位置。全部通过才建议点「一键复制到公众号」。

## 规则清单

| 规则 | 级别 | 判定逻辑 | 改法 |
|---|---|---|---|
| **1.3 行高单位** | 违规 | `line-height` 写成无单位数字（如 `1.8`）。线上旧口径按 `高度 ÷ parseFloat(line-height)` 估行数，`1.8` 会被当 1.8px 解析，误判「行高小于字号，多行文字可能重叠」 | 写成 px（橙墨输出 `28.8px` 这类值），且该元素必须同时有显式 `font-size` |
| **1.3 行高叠字** | 违规 | computed 行高 < 字号，且元素实际高度 > 行高×1.6（多行才会真叠字） | 调大行高至 ≥ 字号 |
| **1.3 行高叠字（官方实测口径）** | 违规 | 复刻官方布局检测兜底分支：对「有直接文本子节点」的块容器取 Range 矩形数当行数，平均行高 < 0.95×字号且矩形数 ≥2 即命中。**正常应恒为 0 项**——正文文字都包在 `<span leaf>` 里；哪天它亮了，说明 `wrapTextRuns` 被误删（见 [wechat-compat.md](wechat-compat.md) 坑 1） | 恢复文本节点包裹，不要手工往块容器里塞直接文本 |
| **1.6 text-align** | 违规 | 显式设置 `text-align:start/end`（逻辑属性值，跨设备对齐不一致）。只查内联显式设置，computed 默认值不误报 | 改 `left / center / right` |
| **3 字体** | 提示 | `font-family` 不在官方白名单内。官方只放行 `"mp-quote", PingFang SC, system-ui, -apple-system` 这一条链，其余（含复制泄漏的系统字体栈）均判违规 | 删掉 font-family，让正文继承默认链 |
| **3.1 嵌套过深** | 违规 | 同标签 + 同样式的单子链连续嵌套 > 15 层，公众号会自动删节点导致版面塌陷 | 扁平化结构（橙墨自身输出不会触发，手工贴 HTML 时注意） |
| **加粗/斜体未生效** | 提示 | 解析后正文残留裸星号 `**` / `*`（v1.0.1 新增）。多半是 CommonMark 分隔符「左右翼」规则：`**` 紧贴中文标点（引号 / 书名号 / 「」/ 句号）时开/收失败。代码块（`code`/`pre`）内星号合法，不报 | 把标点移到 `**` 外面（首选）；或在 `**` 前加空格；或整句独立成行 |
| **对比度（WCAG）** | 提示 | WCAG 2.x AA：正文 ≥4.5:1；大字（≥24px，或 ≥18.66px 且 ≥700 字重）≥3:1。背景取最近一个非透明祖先，页面外层按公众号白底算。同色组合只报一次 | 换更深的文字色或更浅的底色（橙墨内置主题已全部过线） |
| **表格列数** | 提示 | 表格 > 4 列，手机端会被挤压 | ≤4 列，或改列表 |
| **1.8 pre 滥用** | 提示 | `pre` 内长文本且无换行 | 改用 `p` |
| **1.4 宽度溢出** | 提示 | 内联 `width` 超 677px（移动端安全区宽度） | 降宽或用百分比 |
| **空链接** | 提示 | 空 `<a>` 标签（无文字也无图） | 删掉或补内容 |

## 设计口径

- **查渲染结果而非源码**：所有检测都作用在预览区 DOM 上，与复制产出的 HTML 同源。
- **官方口径优先**：行高叠字、text-align、font-family、嵌套层级等条目均以微信公开的 `verify-article-structure-spec` 及线上实测行为为依据；官方排除项（内部无文字、实际单行）同样排除。
- **warn 与 error 分离**：对比度等可读性项不影响发布，混在一起报会稀释真正会拦的违规项的优先级。

## 命令行版

同一套规则（外加复制污染检测、official/real 双口径行高）有独立的 CLI 实现：[aladooo/wechat-article-checker](https://github.com/aladooo/wechat-article-checker)（`pip install wechat-article-checker` / `npx wechat-article-checker`），规则对照见其 `docs/rules.md`。
