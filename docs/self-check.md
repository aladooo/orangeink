# 自检器：微信「结构异常」检测的前端实现

> 本文解释橙墨内置自检器**检查什么、依据什么、怎么判**。命令行版（可脱离工具单独跑）见独立项目 [aladooo/wechat-article-checker](https://github.com/aladooo/wechat-article-checker)。

## 为什么要有自检器

把带样式的 HTML 粘贴进公众号编辑器时，微信会对内容跑一轮**结构合规检测**，不合规就弹「结构异常」警告（例如：「第 2 段：行高小于字体大小，且存在多行文本，可能导致文字重叠」）。

这个检测发生在**发布链路的最后一环**——你排版得再好看，粘贴那一刻被弹窗，就得回头排查。橙墨把同一套检测搬到了编辑器里：点「自检」，**在粘贴之前**预演微信的检查，全部通过才复制。

## 规则依据

- **《微信公众平台编辑器插件开发规范》**（内容校验规则的权威来源）；
- **[wechatjs/verify-article-structure-spec](https://github.com/wechatjs/verify-article-structure-spec)**（官方同步的校验仓库，MIT）。

## 检查项清单

| 检查项 | 判定逻辑 | 依据 |
|--------|----------|------|
| **行高叠字** | 见下节「双口径」 | 官方规范 §2.3.2 line-height-overlapping |
| **font-family 白名单** | 官方仅允许 `"mp-quote", PingFang SC, system-ui, -apple-system` 一条字体链，出现其他字体（**连 `serif` 都算**）即违规 | 官方样式白名单 |
| **WCAG AA 对比度** | 每处文字色相对其实际所在背景 ≥4.5:1（大字号 ≥3:1），含徽章白字 vs 徽章底色 | 无障碍通用标准（官方不查，但读者眼睛查） |
| **空标签** | 微信粘贴解析会**剥掉空标签**（分割线消失事故的根因），输出里不允许出现 | 实测 |
| **无单位行高** | `line-height: 1.8` 这类无单位值会被官方口径按 `1.8px` 估行数而误判，一律要求输出 px | 实测 + 官方口径推演 |
| **复制污染** | 检查剪贴板 payload 是否混入浏览器附加属性（`text-align:start`、`orphans`、`widows` 等） | 实测 |

## 行高叠字：双口径

官方文档 2.3.2 的判定口径（**official**）：

- 矩形数 = `getClientRects().length`；
- 内容高 ÷ 矩形数 < 0.95 × 字号 ⇒ 判定叠字。

这套口径有个著名的副作用：`getClientRects()` 对**一行内的每个行内片段各返回一个矩形**，所以段落里只要有一次 `<strong>` 加粗，矩形数就会大于行数，单行纯文本段落会被数学上无解地误判。

橙墨同时跑两个口径：

- **official**——原样复刻官方算法，**预测公众号会不会弹窗**；
- **real**——按行顶部坐标归并出真实行数，**判断是否真的会叠字**。

两个口径分开汇报：official 有告警但 real 无叠字，说明是检测口径的误报（橙墨的结构策略已尽量规避，见下节）；real 也报，就是真问题，必须改行高。

## 结构策略：为什么输出里全是 `<span leaf>`

官方规范期望的结构是 `<section><span leaf="">文字</span></section>`，且行高叠字检测的兜底分支**只查「有直接文本子节点的块」**。因此橙墨在输出前把**所有直接文本节点包进 `<span leaf>`**——段落里即使有加粗、链接等行内混排，文本也不再是块的直接子节点，official 口径的误判分支被整体绕开。

实测对照（一篇 30 段真文）：不包 span 时 official 报 27/30/23 处，包上后 **0 处**。

这条规则属于渲染管线的**底层结构约定**，改动前请先读 `docs/wechat-compat.md` 的对应小节。

## 使用方式

1. 编辑区写完，点工具栏「自检」；
2. 面板逐项列出违规（含定位与建议），**全部通过（0 项）才建议复制发布**；
3. 自检针对当前预览正文实时重算，深浅主题、字号档位变化后自动覆盖重检。

## 已知边界

- 自检器复刻的是**文档化的检测逻辑 + 实测反推的黑盒行为**，微信随时可能调整规则——遇到「自检全绿但公众号仍弹窗」的情况，请到主仓开 issue 并附上可复现 payload，这比任何功能建议都有价值；
- 自检针对**复制出去的内联样式 HTML**，不检测图片内容、外部链接合规等平台审核维度。
