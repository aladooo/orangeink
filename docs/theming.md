# 主题开发指南（docs/theming.md）

橙墨的主题 = `THEMES` 注册表里的一个 **JS 对象**。切换主题只是重指当前色板 `C` 并重建样式表，无需任何构建步骤。

## 注册表结构

```js
var THEMES = {
  orangeink: {
    name: '橙墨 · 炭黑×亮橙（默认）',
    C: { /* 色板，见下表 */ },
    alerts: { /* 五色提示块 [底色, 左条色] */ }
  },
  // …inkblue / pine / gold
};
```

## 色板键位

| 键 | 用途 | 橙墨值 |
|---|---|---|
| `ORANGE` | accent：条 / 点 / 分割条等装饰（**永远不做正文文字色**） | `#ff5a00` |
| `DEEP` | 标题 / 表头 / 观点卡 | `#1c1917` |
| `EMBER` | H3 / 行内代码（缺省）/ 引用文字 | `#c94a00` |
| `CODE` | 行内代码文字（**可选**，缺省回退 `EMBER`；当 `EMBER` 对 `CODEBG` 对比度不足时单独指定） | `#b84300` |
| `STRONG` | 加粗 | `#c93600` |
| `CHIP` | 徽章 / 序号白字底 | `#d03800` |
| `LINK` | 链接 | `#c23a00` |
| `BROWN` | H4 | `#8c5a2b` |
| `TAN` | 落款 | `#8a663a` |
| `TEXT` | 正文 | `#26221c` |
| `TEXT2` | 题注 / 斜体 | `#6b6154` |
| `TXTQ` | pre / 步骤说明 | `#57503f` |
| `WARMBG` / `WARMBG2` | 模块底（同色系极浅色，米色底模块内部隔线用纯白） | `#fff3e7` / `#faf0e2` |
| `CODEBG` | 行内 code 底 | `#ffe9cc` |
| `ZEBRA` | 表格斑马纹 | `#faf6ef` |
| `LIST2` | 二级列表点 | `#ff8a3d` |
| `BORDER` | 表格框线 | `#e8e0d2` |
| `PTEYE` / `PTNOTE` | 观点卡 eyebrow / note | `#ff9a4d` / `#f3e2ca` |

`alerts` 五键对应五种 GFM 提示块的 `[底色, 左条色]`：`NOTE / TIP / IMPORTANT / WARNING / CAUTION`（emoji 已换成中文徽章，彩色 emoji 会破坏栏目配色，徽章一律白字）。

## 设计方法（四主题同构）

1. 靠**黑白反差**提神，版面主体永远是深字 × 纸白；
2. **单一高饱和 accent 只做装饰**（条 / 点 / 序号），永远不做正文文字色；
3. 一个**暖色阶**负责次级信息（H4 / 题注 / 落款）；
4. 模块底用**同色系极浅色**，不引入新色相。

## 注册规则（硬性）

- 所有**文字色必须过 WCAG AA**：正文 ≥4.5:1，大字 ≥3:1；行内代码文字对 `CODEBG` 同样要过线（`CODE` 键就是为这个存在的——橙墨默认 `EMBER #c94a00` 对 `CODEBG #ffe9cc` 只有 3.98:1，故单独指定 `CODE #b84300` 达 4.63:1）。
- 过不了自检器（对比度 0 项）的主题不允许上线。
- 徽章一律白字，靠底色深浅区分语义。

## 内置主题速览

| 键 | 名称 | accent | 气质 |
|---|---|---|---|
| `orangeink` | 橙墨 · 炭黑×亮橙（默认） | `#ff5a00` | 在场观察、克制提神 |
| `inkblue` | 墨蓝 × 朱砂 | `#bf3b1e` | 冷调证据感 |
| `pine` | 松烟 × 陶土 | `#2e6b46` | 慢内容、互补暖点缀 |
| `gold` | 石墨 × 鎏金 | `#d9a514` | 商业感、强品牌记忆点 |

完整色板值直接看 `src/template.html` 里的 `THEMES` 注册表（文档不复制数值副本，代码是唯一事实源）。

## 贡献新主题

1. Fork → 在 `src/template.html` 的 `THEMES` 里加一个键（含 `C` 全部必填键 + `alerts` 五色）；
2. 跑 `python src/build.py` 重建 `index.html`；
3. 用页面「自检」确认对比度 0 项；
4. 提 PR：附色板 + 各文字色对底色的对比度数值 + 一段示例文截图。
