# 主题总览与选型建议

> 四套主题与主程序同源（同一份 `THEMES` 注册表驱动），本页给全色板速查与选型建议；每套主题的完整设计稿（样张 + 对比度说明）见对应设计页。

| 主题 | 气质 | 适用 |
|------|------|------|
| [**中登 · 炭黑×亮橙**](theme-zhongdeng.html)（默认） | 在场观察、克制提神 | 通用。唯一经公众号**连续发布实测回灌**的主题 |
| [**墨蓝 × 朱砂**](theme-inkblue.html) | 冷调证据感、蓝灰分层 | 深度评测 / 技术解读 |
| [**松烟 × 陶土**](theme-pine.html) | 慢内容、绿底暖点缀 | 随笔 / 生活类 |
| [**石墨 × 鎏金**](theme-gold.html) | 商业感、金线品牌记忆点 | 商业评论 / 年度复盘 |

选型一句话：**拿不准就用默认**——中登主题的每个色值都经过了真实发布流程的检验，其余三套共享同一套结构规则，只在色相气质上分化。

## 对比度

所有主题的文字色均按 WCAG AA 逐背景计算后定值（同一色在不同底色上分别计算）。默认主题五色提示块徽章的实测值：说明 `#d03800` 4.94 / 注意 `#a06300` 4.91 / 重点 `#c93600` 5.23 / 提示 `#8c5a2b` 5.81 / 警告 `#cf3b2a` 4.89（白字均 ≥4.5:1）。

工具内置的对比度检查会在切换主题后自动按当前主题重算，投稿新主题前用它兜底。
